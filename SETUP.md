# Настройка SecureX Manager с MySQL

## Требования

- Node.js 18+
- MySQL 8.0+

## Шаги установки

### 1. Установка зависимостей

```bash
npm install
```

### 2. Настройка базы данных MySQL

Создайте базу данных MySQL:

```sql
CREATE DATABASE securex_manager CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
```

### 3. Настройка переменных окружения

Создайте файл `.env` в корне проекта:

```env
# Подключение к MySQL
DATABASE_HOST=localhost
DATABASE_PORT=3306
DATABASE_USER=root
DATABASE_PASSWORD=ваш_пароль
DATABASE_NAME=securex_manager

# JWT секретный ключ (сгенерируйте случайную строку)
JWT_SECRET=ваш_очень_секретный_ключ_минимум_32_символа

# URL приложения
NEXT_PUBLIC_APP_URL=http://localhost:3000
```

### 4. Импорт схемы базы данных

Выполните SQL скрипт для создания таблиц:

```bash
mysql -u root -p securex_manager < database/schema.sql
```

Или через MySQL Workbench/phpMyAdmin откройте файл `database/schema.sql` и выполните его.

### 5. Создание администратора

Схема автоматически создаст пользователя-администратора:
- **Логин**: PROXT
- **Пароль**: 32Ipubib5429

### 6. Запуск приложения

```bash
# Режим разработки
npm run dev

# Продакшн сборка
npm run build
npm start
```

Приложение будет доступно по адресу: http://localhost:3000

### 7. Первый вход

1. Откройте http://localhost:3000/login
2. Войдите с учетными данными администратора
3. Измените пароль администратора в настройках пользователей

## Структура базы данных

### Таблицы:

- **users** - Пользователи системы
- **cards** - Доступы к сайтам
- **card_items** - Элементы доступов (логины, пароли, ссылки)
- **tasks** - Задачи

### Безопасность:

- Пароли хешируются с использованием bcrypt
- JWT токены для аутентификации
- HTTP-only cookies для защиты сессий
- Проверка прав доступа на уровне API

## Возможные проблемы

### Ошибка подключения к MySQL

Проверьте:
- Запущен ли MySQL сервер
- Правильность учетных данных в `.env`
- Существует ли база данных
- Доступен ли MySQL на указанном хосте и порту

### Ошибка JWT

Убедитесь, что `JWT_SECRET` установлен и содержит минимум 32 символа.

### Ошибки импорта схемы

Убедитесь, что используете MySQL 8.0+, так как схема использует современный синтаксис.
